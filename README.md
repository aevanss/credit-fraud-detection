# Credit Card Fraud Detection -- in progress

I want to find credit fraud from this dataset. Working through this because of the potential challenges that it may cause, namely:
 large class imbalance
 asymmetrical cost: false negative (missed fraud) costs real money; false positive (flagging a legit purchase) costs customer annoyance
 features are anonymized 
 fraud patterns shift over time, will need to update as fraud tactic changes over the years
